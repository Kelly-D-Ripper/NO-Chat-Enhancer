# Chat Enhancer 2.0.1

The chat box got a proper overhaul. You're welcome.

- A new look with **All**, **Chat** and **Kills** tabs.
- Filter out AI-on-AI kills, interceptions and other combat chatter you don't need.
- Tweak the display, timestamps and compact feed in-game.
- Fixed those lovely raw `<link="player:...">` tags appearing around player names.

This is the **client** download. Long player messages still need compatible server and client installations with matching limits; see the README if you're playing on an unmodded server.

The redesigned interface hasn't yet been visually verified in-game. If anything looks wonky, let me know.
